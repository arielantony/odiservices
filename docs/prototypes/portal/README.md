## Amendments to v3

v3 was approved on 2026-10-30 with these amendments. `v3.html` is not edited.
The next version (v4) carries them, and the specs already apply them:

1. **"Equipe financeira"** in the top bar uses opacity 1 instead of .8. At .8
   its contrast is 4.2:1, which fails AA. At 1 it is 6.9:1 (FE-01 spec, Q1).
2. **Screen width:** v3 screens are 1280px wide. The standard is 1360px
   (`docs/CONSTITUTION.md`, Article 3), and v4 onward uses it.
